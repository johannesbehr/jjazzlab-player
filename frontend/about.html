An independent proof-of-concept

JJazzLab Player is a private proof-of-concept exploring how JJazzLab functionality could work in a web browser.

This is an independent, experimental project and is not an official part of JJazzLab. It is intended to explore what might be possible and perhaps serve as a starting point for further ideas and development.

The project is currently very much a work in progress. Features are incomplete, things may break, and the service can change or disappear at any time. Check out the jjazzlab-player repository on github.

This website is not intended for productive use. Please do not rely on it for important work or data.

This website makes use of the JJazzLab-Toolkit. For the full and official JJazzLab experience, please visit the official JJazzLab website.
